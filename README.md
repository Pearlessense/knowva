## ✧ About [knowva.lol](https://knowva.lol/)
Most Discord bots focus on moderation or entertainment. Knowva takes a different approach — prioritizing **automation** to help servers stay organized and productive.

**Why try Knowva?**

- **Free to use** → Optional premium perks unlock advanced features.
